
# 11) UI/UX and admin correctness

Checklist:
- Admin pages: correct caps, correct escaping, Settings API usage where appropriate.
- Notices: dismissible, non-spammy, not shown to unauthorized users.
- Load assets only on plugin screens.
- Accessibility: labels, keyboard navigation, ARIA where needed.
- UX flows: actionable errors; confirmations; destructive actions gated.

This is often manual and requires an interactive environment.
